## Set up your environment

Learn how to get started with your Frontend Handbook locally and customize it to your needs.

### Clone and run locally

<AccordionGroup>
  <Accordion icon="github" title="Clone the project">
    First, clone the repository containing your handbook files. Run the following in your terminal:

    ```bash
    git clone https://github.com/alireza-akbarzadeh/frontend-handbook
    cd frontend-handbook
    ```

    Make sure you have Node.js installed. You can download it from [nodejs.org](https://nodejs.org).

  </Accordion>

  <Accordion icon="rectangle-terminal" title="Install dependencies and start development server">
    Install the dependencies and start the development server using the following commands:

    ```bash
    npm install -g mintlify
    mintlify dev
    ```

    This will launch your handbook locally at `http://localhost:3000` (or another port depending on your setup).

  </Accordion>
</AccordionGroup>

### Customize and preview

<AccordionGroup>
  <Accordion icon="pen-to-square" title="Edit your content">
    Edit the `.mdx` files inside the `html/`, `css/`, `javascript/`, or `git/` folders to update or add new topics.

    For example:
    - `html/introduction.mdx`
    - `css/flexbox.mdx`

    Use Markdown with React components to build interactive content.

  </Accordion>

  <Accordion icon="eye" title="Preview your changes">
    Your changes will be hot-reloaded in the browser. Just refresh or navigate to the page you're editing to see updates instantly.
  </Accordion>
</AccordionGroup>

## Deploy your handbook

<AccordionGroup>
  <Accordion icon="rocket" title="Deploy using GitHub Pages / Vercel / Netlify">
    You can deploy your handbook using a static site hosting provider:

    - **GitHub Pages** – via GitHub Actions
    - **Vercel** – automatic deploy on push (recommended for Next.js)
    - **Netlify** – drag and drop or connect your repo

    Most setups just require pushing your code to GitHub.

  </Accordion>

  <Accordion icon="upload" title="Push your changes to GitHub">
    Commit and push your changes:

    ```bash
    git add .
    git commit -m "Update handbook content"
    git push origin main
    ```

    Your deployment provider will detect the change and redeploy your site.

  </Accordion>
</AccordionGroup>
